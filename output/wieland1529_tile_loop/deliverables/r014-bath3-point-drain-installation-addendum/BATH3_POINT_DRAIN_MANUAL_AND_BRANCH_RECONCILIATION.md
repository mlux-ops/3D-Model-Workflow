## Actual instructions read — narrow technical progress, not a certified waterproofing system

- **Delta PH, official 113919 Rev B, pages 2–5:** Lower-body flange location and 2-in PVC plumbing connection must be coordinated with the slab/subfloor and actual drain center. The published method sets a presloped mortar bed at **1/4 in per ft (approximately 2%)** toward the lower drain body, then a clamped, reinforced waterproof liner with stated wall/curb returns and a water-retention test before tile. The manual also addresses the collar, weep holes and upper-body elevation. The exact manual sheets must control over this summary.
- **Brizo TX, official 113920 Rev C, pages 2–5:** Separate selected original Brizo BT062415-series instructions likewise depict a sloped mortar bed, bolted drain collar, waterproof sheet pan liner, water-retention test and weep-hole/tile-layer coordination. The manufacturer method is **not** evidence that an arbitrary bonded surface membrane or foam tray has been approved with these drains.
- **GC installation request for EACH selected point drain if and only if WALK-IN chosen:** Provide exact purchased model/finish, all parts and lower-body assembly, trap/vent and drain-center survey, subfloor build-up, individual finished LEVEL-to-PAN boundary, slope arrows/four plane geometry, membrane manufacturer and compatible clamping/detail specification, pre-slope/mortar sections, wall/curb transition, grate edge and tile thickness, weep protection, test duration/acceptance under Chicago requirements, trim and glass shop. Coordinate manufacturer instructions with governing local code. No substitutions without owner/architect written acceptance.
- **TUB option remains separate:** All proposed tiled four-plane shower PAN documentation would be N/A. Tub SKU, physical envelope, waste-and-overflow, anti-migration supports, tub flange/backer waterproof termination, shower-fixture outlet and glass/curtain terminations require owner/architect/GC signoff before a TUB drawing or material quantity can be issued.

The manuals show a manufacturer-described installation sequence, **not an actual project-matched completed assembly**.
