# R030 blind BUILD critique — PH-PRIMARY

**Seat:** BUILD, independent tile installer/general contractor. **Scope:** candidates A and B independently, two physical bathrooms 304A/304B. Each criterion is rated 1–5. Overall BUILD score is the unweighted arithmetic mean, rounded to one decimal. This is tile-selection constructability assessment, not installation approval or a fabricated shop layout.

**Fixed room program:** walk-in shower and separately selected Duravit Starck 67 × 36-in built-in tub; Brizo Roccesco Black Onyx (BNX) fittings; 48-in Brizo BT0734816-BNX **factory solid-metal LINEAR grate** with **separate BR73480 rough/channel per shower**. No tile-in insert, no niche. WC uses the parent LEVEL floor tile without a second order line. Shower tiled ceiling is a distinct **unselected overhead HOLD**. Room geometry is drawing-derived: W1 5.854 ft and W2 4.646 ft at assumed 9.25-ft tiled height; actual wall, glass, thresholds, drains and field offsets are not receipt-verified. Sources: [Brizo trim](https://www.brizo.com/bath/product/BT0734816-BNX), [Brizo rough](https://www.brizo.com/bath/product/BR73480), own geometry.json and plumbing.json.
