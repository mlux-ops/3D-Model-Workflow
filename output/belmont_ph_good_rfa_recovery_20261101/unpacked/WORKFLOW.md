Revit's **Shaded** graphics transparency is not Realistic render transparency. For transparent globes, use a native `DisplayStyle.Realistic` view with a black-and-white checkerboard just behind the glass, compare saved images directly, and fail the optical gate if transmission is not visible. Preserve original geometry and painted glass faces while diagnosing composite clear/frosted surfaces. Realistic checker tests only establish whether the view transmits; calibrated refraction, edge reflectance and manufacturer tint still require visual acceptance.

For native read-only QA, cast .NET `Color.Red/Green/Blue` values to Python `int` before JSON serialization in IronPython 2.7. For hiding test host elements use `host.CanBeHidden(view)`, not the nonexistent `view.CanElementBeHidden` on `View3D`. Record each failing run and only retry in a newly named script/output revision after changing the cause.

## Efficiency rules learned from earlier project logs

- Reuse a stable, already running Revit session. Earlier `pyrevit run` opened a new Revit 2025 process and stalled for approximately nine minutes before a startup exception; an already-open pyRevit command was the working recovery.
- Prevent partial-state contamination: group changes into atomic transactions, rollback on errors and close failed documents reliably. Earlier parameter group API mismatch caused seven initial failures; use the actual version-specific group identifier (`Geometry` for the tested Revit 2025 path).
- Regenerate before asking for host wall faces; earlier host validation failed because a newly created wall had not regenerated.
- Keep exact SKU in RFA identity, but sanitize periods and illegal characters in export-image prefixes independently; a period previously caused exported previews to be saved under shortened names.
- Validate as-built full envelope against published dimensions and report limitations rather than silently accepting a CAD/model mismatch. Check left/right part inventory in addition to numerical bounding boxes.
- Parallelize manufacturer research, metadata extraction and source QA; keep native Revit document mutation serialized through a single locked runner.
- **Queue reliability:** one misleading connector `UNAVAILABLE` prompted a 336-second duplicate queue; check the runner's owned process and receipt before any retry. Keep family batches bounded and isolate visual/image retrieval from native geometry operations.
- **Bound geometry preflight:** the Panasonic grille exposed IronPython integer division (`15.5` became `16` inches); force float arithmetic and measured numerical assertions. Three-point arcs overshot Dew Drops/Faro envelope; model with tangent or ellipsoid profiles. Avoid wire revolutions shorter than `ShortCurveTolerance` (Orion), and constrain cosmetic radius to the actual solid envelope (Hinkley/Vista).
- **Harden intake/verification:** one Zephyr OEM ZIP was truncated; verify signature and expected archive entries. Use UTF-8 without BOM for JSON receipts. Exclude untouched template solids from dimension bounds. Revit Family Editor views may reject `View.SetElementOverrides`; put preview finishes on material parameters instead of forcing family-view graphics overrides.
- **Time handling:** the last plumbing family batch took around 22 seconds waiting for native lock and 40 seconds for runner exit. Record lock wait separately from geometry and preview time to identify actual bottlenecks.
- **Visual review optimization:** favor dimensioned drawings plus limited front/side/oblique images during geometry evaluation; a full Panasonic mesh/image review stalled for roughly 240 seconds. Skip repetitive image inference once source identity and key dimensions have passed; retain one human-reviewable proof set.
