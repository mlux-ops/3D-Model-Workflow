Step 8.4, part 2, run while the data-sheet search of J5 is still going: how the engine turns a photometric file into light, measured before any fixture is set. One temporary light 1 m above the 50 percent card, 55 m up in open air, with the sun and the sky light switched off for the duration (not saved) so that the card sees only this light. Cases: (a) no file, 1,000 lumens (Phase 1 read 79.6 lux for this); (b) the file of the EAE downlight that came with the model (2,231 lumens, 795 candela straight down by the file) with the light's own value set to 2,231 lumens; (c) the same with the option that takes the brightness from the file. The right setting is the one where the card reads the file's candela value straight down (795 lux at 1 m). Also read: which way a file's downward direction points relative to the light's own axes. Nothing is saved; the sun and sky light are switched on again and checked against the J4 reading.
