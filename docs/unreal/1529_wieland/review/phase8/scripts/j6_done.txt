The card 1 m below the light read: (a) no file, 1,000 lumens: 79.4 lux (Phase 1: 79.6); (b) the EAE file with the light's own value at 2,231 lumens: 176.9 lux, not 795, because the engine uses the file only as a shape whose brightest direction is 1 and takes the brightness as lumens divided by 4 pi; (c) brightness taken from the file: 63.1 lux whatever the lumens, because the engine treats the file's 795 candela as if it were lumens (795 divided by 4 pi); with the file's scale set to 4 pi: 792.4 lux; (f) the light's unit set to candela and its value set to the file's largest candela value (794.9), brightness not taken from the file: 792.4 lux, which is the file's own number within 0.4 percent. Rule used from here on: each light with a photometric file gets its unit set to candela and its value set to the file's largest candela value, multiplied by wanted lumens over the file's lumens where the two differ; a light without a file gets plain lumens. Direction: the file's straight-down direction is the light's forward axis (turned level or upward the card read 0.15 and 0.27 lux), so a ceiling fixture's light has to point its forward axis down.
