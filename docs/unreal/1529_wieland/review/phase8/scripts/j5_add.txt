Step 8.4, part 1: the fixture table. Every one of the 571 lights that came with the Revit model is listed by Revit element id with its fixture kind (family and type), and the kinds are counted. For each kind the manufacturer's data sheet and photometric file (a file that describes in which directions a fixture sends its light) is looked for: first among the 8 that came with the import, then at the manufacturer (no cost, under 50 MB together, each download in its own new folder under `E:\Wieland1529_site_data\photometry\`, each recorded in `asset_downloads.csv` with its licence). The table `review\phase8\fixture_table.csv` gets, per kind: maker, model, light output in lumens, colour temperature in kelvin, photometric file, and the source of each number. Where the model names no product, the kind gets a generic value that is labelled as such and waits on the owner. Nothing in the Unreal project changes in this step.
