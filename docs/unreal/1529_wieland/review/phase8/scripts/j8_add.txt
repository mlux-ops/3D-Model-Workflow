Step 8.4, part 3: the fixtures are lit from the table `review/phase8/fixture_table.csv` (written by `review/phase8/scripts/j5_table.py`; 22 kinds, 571 lights). Order: (a) each photometric file is imported as a new asset of its own under `/Game/Wieland1529/Lighting/Photometric` and saved by name; the assets Datasmith made are not used or touched. (b) ONE fixture first, a recessed can light: its settings are applied with `wieland_fixtures.apply(..., only_revit_ids=...)`, a matte card is placed 1.5 m beneath it and read in lux, and the reading is compared with the candela value over the distance squared. This also answers whether the fixture's own mesh, which the probe `j8_probe.py` found within 2 cm of the light, blocks it. (c) only when (b) is right, all 571 lights; the result is written to `review/phase8/fixture_lights.csv`. (d) the four unit levels are saved by name. The lights are changed in the unit levels, which are this project's own copies since Phase 6, as settings on the placed lights; no asset that Datasmith created is edited. Memory is read before (c).
